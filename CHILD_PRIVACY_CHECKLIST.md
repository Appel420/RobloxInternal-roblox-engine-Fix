# Children's privacy checklist

Use this checklist before releasing a child-facing feature.

## Checklist

- [ ] Age gate is in place
- [ ] Parental consent flow is documented
- [ ] Privacy notice is published
- [ ] Data collection is minimized
- [ ] Voice collection is disabled or justified
- [ ] Retention periods are defined
- [ ] Deletion requests are supported
- [ ] Moderation paths avoid unnecessary storage
- [ ] Human review exists for borderline child cases
- [ ] Legal review is complete

## Notes

This checklist is a process aid, not a legal guarantee of compliance.
