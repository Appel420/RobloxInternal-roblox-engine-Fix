# Privacy

This repository contains template guidance for privacy notices, consent flows, and retention rules.

## What this covers

- Data collection limits
- Child-account protections
- Verifiable parental consent
- Retention and deletion expectations
- User access, correction, and deletion paths

## Guidance

- Keep notices plain and accurate.
- Default to the most restrictive safe settings.
- Collect only what is required for the feature.
- Update privacy language when data flows change.
