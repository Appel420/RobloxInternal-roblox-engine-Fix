# Verifiable parental consent

This is a template for a consent workflow for child accounts.

## Include

- Age screening before account creation or feature access
- Parent or guardian contact flow
- Verification method for consent
- Record of consent status
- Re-consent flow for material changes
- Withdrawal of consent and account handling

## Guidance

- Use a consent method that matches the risk level of the data collected.
- Store only the minimum records needed to prove consent.
- Separate consent for optional features from consent for required service functionality.
